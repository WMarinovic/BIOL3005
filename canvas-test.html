Canvas test for the tutorial pages

This page checks whether everything the weekly Tools pages need works where you opened it. Run the tests in order; most take a few seconds. At the end you will get a recommendation and a short results code.

Not workingScripts are blocked here. The Tools pages cannot run in this view. Look for a way to open the file in a new tab, or download it and open it from your computer.

1. Where am I?

Checks whether Canvas is showing this page inside a frame.

2. Screen refresh

Measures the refresh rate that sets how long brief displays last.

3. Full screen

The task runs full screen. The page will go dark for two seconds, then return.

4. Keyboard

Click the button, then press the X key, the N key and the spacebar.

5. Copy

Copies a test line. Then paste it anywhere (a Teams chat, a document) to check.

6. Download

Saves a small file called canvas_test.csv. Check your Downloads folder, then say whether it arrived.

7. Sound

Plays a short beep (used as a warning signal in Week 1).
