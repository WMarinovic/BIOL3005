BIOL3005 Cognition, Week 10 tutorial

Stuck in a rut

Tools for the problem-solving lab: Luchins’ (1942) water-jug problems, with half the class trained into a mental set and half not. Textbook Chapter 10, §10.6 and §10.8.

Try one

You have three jugs: A holds 21, B holds 127 and C holds 3 units, and an unlimited tap. How do you measure exactly 100?

Write your answer using the jug letters, for example B-A-C or A+2C.

What the task is doing

Each problem gives you three jugs and a target amount. You write how to get the target by filling and pouring, as a short formula: B-A-2C means fill B, pour off one A and two Cs.

The class is split at random. One group first solves five problems that all need the same long method. The other group starts straight at the test problems. Some test problems can be solved by the long method or by a much simpler one; one can only be solved the simple way.

Does practising one method make the simple one invisible? That is mental set, and Luchins showed it in 1942.

Run the task

The task runs full screen and takes about 8 minutes. You need a keyboard.

  1. Each problem shows three jugs and a target. Type how to measure the target, using the jug letters, and press Enter. For example, B-A-2C.
  2. If your answer is wrong you can try again. You have up to two minutes per problem, or you can give up.
  3. You will not be told which group you are in until the end.
Settings for tutors

Students are randomly assigned to the set group (warm-up problem 1, training problems 2 to 6, then test problems 7 to 11) or the control group (problem 1, then test problems 7 to 11, then problems 2 to 6 as extras that are not analysed). Capacities and targets are Luchins’ (1942), as in Table 10.1. Answers are checked automatically and classified as the long method (B − A − 2C), a short method (two or three pours) or other. Problem 9 can only be solved the short way.
